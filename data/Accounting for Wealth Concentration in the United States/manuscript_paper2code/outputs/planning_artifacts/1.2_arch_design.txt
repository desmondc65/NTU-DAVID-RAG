[Implementation approach]
The solution implements a lifecycle Overlapping Generations (OLG) model with heterogeneous agents to study wealth concentration. We will use a modular Python architecture centered around an 'Endogenous Grid Method' (EGM) to solve the household's consumption-savings-labor problem efficiently. The system is divided into an empirical module (processing SCF data and imputing labor shares), a household solver module (backward induction for 16 periods), and a general equilibrium module (solving for market clearing $K$ and $N$). Performance will be optimized using Numba for the nested loops in value function iteration. The experiment runner will programmatically disable model features (bequests, superearners, return heterogeneity) to conduct the decomposition analysis described in the paper.
