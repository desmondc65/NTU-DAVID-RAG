The `utils.py` module serves as the mathematical backbone for the overlapping-generations (OLG) model. It provides optimized, low-level functions required for stochastic process discretization, solving complementarity problems (labor supply decisions), and multi-dimensional interpolation of the value functions.

### 1. Stochastic Process Discretization: Rouwenhorst Method
The paper specifies that earning abilities ($e_1, e_2$) follow a first-order Markov process (AR(1)) in logs: $\ln z_{j,i} = \rho \ln z_{j,i-1} + \epsilon_{j,i}$. We implement the Rouwenhorst method to discretize this into `num_abilities` nodes ($N=5$ in `config.yaml`).

*   **Grid Calculation**:
    *   Calculate the standard deviation of the stationary distribution: $\sigma_z = \frac{\sigma_{\epsilon}}{\sqrt{1 - \rho^2}}$ (using `rho` and `sigma_epsilon` from `config.yaml`).
    *   Define the step size $\psi = \sigma_z \sqrt{N-1}$.
    *   The log-grid is symmetric: $\{-\psi, -\psi + \Delta, \dots, \psi\}$ where $\Delta = \frac{2\psi}{N-1}$.
    *   The actual earning ability grid $E$ is $\exp(\text{log-grid})$, normalized such that the mean of the exponentiated values is consistent with the paper’s lifecycle profiles.
*   **Transition Matrix ($P_N$)**:
    *   Construct $P_2 = \begin{bmatrix} p & 1-p \\ 1-q & q \end{bmatrix}$ where $p = q = \frac{1+\rho}{2}$.
    *   Recursively build $P_N$ following the standard Rouwenhorst formula, ensuring rows sum to 1.
*   **Initial Variance (Age 21)**:
    *   The paper (Footnote 8/Section 3.4) sets $V(\ln z_{j,21}) = 0.5 \frac{\sigma_{\epsilon}^2}{1 - \rho^2}$. This affects the initial distribution of abilities for newborn households in `economy.py`.

### 2. Intra-family Wage Correlation Logic
Per Section 3.4 of the paper, married households ($m=0$) have correlated earning abilities.
*   **Joint Unconditional Probability**: $\pi(e_1, e_2) = \omega \cdot \text{diag}(\pi_{e_1}) + (1-\omega) \cdot (\pi_{e_1} \pi_{e_2}^T)$, where $\omega = 0.29$ (`wage_corr_omega` in `config.yaml`).
*   **Joint Transition Probability**: Implement the logic to calculate $P(e_{1,i+1}, e_{2,i+1} | e_{1,i}, e_{2,i})$. 
    *   If the husband and wife are on the diagonal ($j=k$), the conditional probability is a weighted average of perfectly correlated and uncorrelated transitions using the parameter $\omega'$ (the conditional probability of being perfectly correlated given current diagonal position).
    *   This logic is essential for the expectation step in `household.py`.

### 3. Complementarity System: Fischer-Burmeister Functions
To handle the Kuhn-Tucker conditions for labor supply ($h_j \ge 0$ and $h_j \le 1 - \text{leisure\_constraints}$), we transform the inequality constraints into a system of differentiable equations.

*   **Primary Function**: $\phi(u, v) = u + v - \sqrt{u^2 + v^2}$. This function has the property $\phi(u, v) = 0 \iff u \ge 0, v \ge 0, uv = 0$.
*   **Application in MRS**: Used to solve for the multipliers of the non-negativity constraints on work hours.
*   **Max-Operator Variation**: $\phi^+(u, v) = u + v + \sqrt{u^2 + v^2}$ (as described in Appendix A.1).
*   **Numerical Stability**: Implement with a small $\epsilon$ inside the square root ($\sqrt{u^2 + v^2 + \epsilon}$) to ensure differentiability at $(0,0)$, which is critical for the Newton-type solver in `household.py`.

### 4. N-Dimensional Linear Interpolation (`nd_interp`)
The state space consists of discrete (Age $i$, Marital Status $m$, Ability $e$) and continuous (Assets $a$, Historical Earnings $b_1, b_2$) variables. During backward induction, we must interpolate $V_{i+1}$ over continuous states.

*   **Target State**: $(a', b_1', b_2')$.
*   **Grid Structure**:
    *   $a \in [a_{min}, a_{max}]$ (27 nodes, non-uniform/log-spaced).
    *   $b_1, b_2 \in [0, b_{max}]$ (15 nodes, customized to include bend points $\vartheta_1, \vartheta_2$ from `config.yaml`).
*   **Algorithm (Trilinear Interpolation)**:
    1.  Identify the surrounding hypercube (8 vertices for 3D interpolation on $a, b_1, b_2$) in the grid for each continuous state.
    2.  Calculate weights based on the relative distance of the target point from the grid nodes.
    3.  Compute the weighted sum of the values at the vertices.
*   **Performance Optimization**: 
    *   Use `@numba.njit` to compile the interpolation logic to machine code.
    *   Since the grids for $a, b_1, b_2$ are fixed across iterations, pre-calculating index-finding logic (e.g., using `np.searchsorted`) within the jitted function is required to minimize overhead.

### 5. Gamma Distribution Utilities
The household receives random utility $\chi$ from staying at home (Section 2.1).
*   **Parameters**: Scale $\theta = 2.0$ (`theta_gamma_dist`) and shape $\bar{\alpha}$.
*   **Expectation Helper**: Implement a function to calculate $E[\chi | \text{choice}]$, specifically for cases where the household chooses between working and staying at home. The paper notes that the Gamma distribution allows for a specific formula for $E[\chi - d | \chi > d]$, used in Appendix A to smooth discrete choices and ensure convergence.
