The logic analysis for `visualization.py` focuses on translating the numerical results from the steady-state and transition solvers into the key graphical representations presented in the paper. This module is essential for validating the reproduction against the paper's findings.

### Logic Analysis: `visualization.py`

#### 1. Figure 1: Tax System Progressivity (U.S. Status Quo)
*   **Purpose**: Demonstrate the fit of the log-linear tax function $y^d = \lambda y^{1-\tau}$ to the U.S. status quo.
*   **Data Source**: `SteadyStateSolver` output for the benchmark economy ($\tau = 0.17$ from `config.yaml`).
*   **Logic**:
    *   Generate a range of pre-tax income $y$ from the distribution $\Gamma(k, z)$ (from the bottom 1% to the top 1%).
    *   Calculate disposable income $y^d$ using the function $y^d = \lambda y^{1-\tau}$ with the calibrated $\lambda$ from the benchmark equilibrium.
    *   Calculate the average pre-tax income for various quantiles to simulate the "circles" shown in the paper.
    *   **Plotting**: 
        *   X-axis: $\ln(\text{Pre-tax Income})$.
        *   Y-axis: $\ln(\text{Disposable Income})$.
        *   Include a 45-degree line (dashed) representing a zero-tax system for reference.
        *   Plot the model-fitted line (solid) with slope $1-\tau$.

#### 2. Figure 2: Welfare by Wealth and Productivity
*   **Purpose**: Compare the value functions $V(k, z)$ between the benchmark and the long-run optimal regressive system.
*   **Data Source**: `HouseholdPolicy` objects from the benchmark steady state ($\tau = 0.17$) and the optimal steady state ($\tau = -0.09$ from `config.yaml`).
*   **Logic**:
    *   Identify the indices for the lowest productivity state ($z_{min} = f_L + a_L$) and highest productivity state ($z_{max} = f_H + a_H$) from `EconomyConfig`.
    *   Extract the Value Function $V(k, z)$ slices for these productivity levels across the `k_grid`.
    *   Identify the aggregate capital $K_{benchmark}$ and $K_{optimal}$ to mark average wealth.
    *   **Plotting**: 
        *   X-axis: Wealth ($k$).
        *   Y-axis: Welfare/Value Function $V$.
        *   Use solid lines for the benchmark and dashed lines for the optimal regressive policy.
        *   Mark average wealth using vertical lines as indicated in the paper’s notes.

#### 3. Figure 3: Transition to Regressive Taxation
*   **Purpose**: Visualize the path of aggregates and inequality when switching from the U.S. benchmark to the long-run optimal $\tau = -0.09$.
*   **Data Source**: The `dict` returned by `TransitionSolver.solve_path()`.
*   **Logic**:
    *   The path sequence $\{K_t, N_t, C_t, r_t, \lambda_t, Gini(C)_t\}$ is extracted.
    *   **Normalization**: For $K, N, C$, divide each value by the initial steady-state value (Period 0) to show percentage changes relative to the benchmark.
    *   **Inequality Calculation**: For each period $t$, use the simulated distribution $\Gamma_t(k, z)$ and the policy $c_t(k, z)$ to calculate the Gini coefficient for consumption.
    *   **Plotting**: 
        *   A 2x2 or 3x2 grid of subplots.
        *   X-axis: Time in years (Period index $\times$ 5, as `period_years` = 5 in `config.yaml`).
        *   Y-axis: Relative values (except for $r_t$, which is plotted as an annual percentage).

#### 4. Figure 4: Government Altruism and Optimal Tax Progressivity
*   **Purpose**: Show how the optimal $\tau$ chosen by the policymaker changes as they value future generations more (increasing $\beta_g$).
*   **Data Source**: A collection of optimization results from `Main` where the `TransitionSolver` was run for various $\beta_g \in [0, 1)$.
*   **Logic**:
    *   Collect pairs of $(\beta_g, \tau^*)$, where $\tau^*$ is the progressivity parameter that maximizes the social welfare function (Equation 6 in the paper).
    *   Identify the specific points $\beta_g = 0$ (current generation only) and $\beta_g = \beta$ (altruistic parent weight, where $\beta$ is the annual discount factor converted to a 5-year period value from `config.yaml`).
    *   **Plotting**: 
        *   X-axis: Policymaker's discount factor for future generations ($\beta_g$).
        *   Y-axis: Optimal Progressivity ($\tau$).
        *   Draw a smooth curve through the points.

#### 5. Auxiliary Calculation: Gini Coefficient
*   To support Figure 3 and the result tables, a helper function is required to calculate the Gini coefficient from a discretized distribution:
    *   $G = \frac{\sum_i \sum_j \Gamma_i \Gamma_j |x_i - x_j|}{2 \sum_i \Gamma_i x_i}$, where $x$ is the variable of interest (wealth, disposable income, or consumption) and $\Gamma$ is the mass at that point.

#### 6. Reference to Configuration (`config.yaml`)
*   **Grid Bounds**: Use `k_min` and `k_max` for setting plot limits on wealth axes.
*   **Timing**: Use `transition_periods` to determine the X-axis range for Figure 3.
*   **Targeting**: Compare simulated $r$ in Figure 3 against `r_annual_target` (4.1%) to ensure the transition starts from the correct baseline.
